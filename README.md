# Интерактивный ГИС-модуль картографирования инцидентов ЖКХ

Проект на Python, выполняющий автоматическое слияние ведомственных показателей аналитики с полигонами географических границ Московской области для визуализации пространственных паттернов аварийности.

## Архитектура решения и UX-кастомизация
* **Пространственное слияние (Spatial Join):** библиотека `geopandas` осуществляет left join табличных данных Excel со слоем полигонов GeoJSON на основе нормализованных текстовых наименований округов.
* **Низкоуровневый патчинг Folium:** для реализации контрастной белой подсветки полигонов при наведении курсора (hover effect) в Python динамически переопределены JS-методы `style_function` и `highlight_function` внутренних элементов веб-карты Leaflet.
* **Кастомная инъекция стилей:** в заголовок Folium-объекта внедрен кастомный CSS-фреймворк и JS-код, удаляющий лишние элементы копирайта Leaflet из DOM-дерева и кастомизирующий меню выбора слоев под UI-стандарты ведомства.

## Как запустить проект локально
1. Клонируйте репозиторий или скачайте файлы проекта.
2. Установите зависимости:
   `pip install pandas geopandas openpyxl folium`
3. Запустите скрипт:
   `python map_generator.py`
Скрипт автоматически обработает демонстрационные (mock) данные из папки `data/` и откроет готовую интерактивную веб-карту в вашем браузере.
